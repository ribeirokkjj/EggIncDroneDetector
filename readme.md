# Egg, Inc. Drone Clicker Setup Guide

Follow these steps to configure your screen and launch the automation script.

---

## Step 1: Set Up BlueStacks & Egg, Inc.

1. **Launch BlueStacks** and open **Egg, Inc.**.
2. **Enable Fullscreen:** Switch BlueStacks to full-screen mode by pressing `F11` (or clicking the fullscreen icon on the side toolbar).
3. **Navigate to Shells:** Open the game menu and go to the **Shells** tab.
4. **Target the Silo:** Highlight or select the **silo closest to the research building** (the one located at the far edge).

---

## Step 2: Run the Script

1. Run droneclicker.py
2. Once launched, the script will automatically track the entire monitor and move your mouse to click passing drones.
